# Dự án Dự báo giá nhà (House Price Prediction)

Dự án này sử dụng mô hình Hồi quy tuyến tính (Linear Regression) để dự báo giá nhà dựa trên các đặc trưng đầu vào.

## Yêu cầu (Requirements)
- Python 3.x
- pandas
- scikit-learn

## Cách chạy (How to run)
1. Cài đặt các thư viện cần thiết: `pip install pandas scikit-learn`
2. Chạy file mã nguồn: `python main.py`

## Thông tin nhánh
- Phiên bản hiện tại đang chạy trên nhánh: `version 2`
